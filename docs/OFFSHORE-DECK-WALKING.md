# 远海浮动岛：移动甲板行走

## 玩家流程

1. 在远海浮动岛观景面板选择“登船并出海”。
2. 选择“甲板行走”，或者关闭观景进入“跟随人物”。
3. 使用 WASD／方向键，手机使用屏幕方向按钮。在跟随模式下按住右键拖动，手机拖动画面环视。
4. “航程控制”可重新打开观景、提前返航；船靠港后才能下船。

移动平台第一期只开放安全甲板行走，不开放跳跃、喷气或离船入海。靠港下船后恢复原有岸上跳跃／喷气操作。镜头、暂停输入和重连不重置航程，不把乘客送回初始观景位。

## 权威与空间

- 协议版本为 **9**。版本 8 及更早版本必须刷新，防止旧客户端按世界坐标解释船上输入。
- 服务端唯一接收方向输入 `x/z`，船上表示船体局部方向。客户端不提交位置、速度、高度或朝向。
- `deckX/deckZ/deckYaw` 为船体局部权威状态。客户端本地预测、服务器 20 Hz 更新、远端插值使用同一套几何。
- 速度 4.2 米／秒，斜向归一化，单次模拟最多 0.1 秒，每子步最多 0.12 米；输入 300 毫秒过期后停止。
- 甲板外缘、中央月池、舱楼、吊机底座、救生艇及设备架均不可穿越。碰撞半径 0.4 米，支持贴墙滑动。
- 走路坐标随后经过与船模型相同的 XYZ 旋转及平移，包含船体颠簸、横摇和纵摇，不产生转弯时的人物滑移。
- 相机在船局部空间逐段检测实体设施和甲板高度，再与船体一起变换；不会从人到镜头之间穿过舱楼。
- 保留原有 150 秒路线、8 人容量、自动返港和提前返航行为；断线保留已走到的甲板位置，恢复连接后不自动恢复旧的移动输入。
