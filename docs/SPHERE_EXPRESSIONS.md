球幕表情升级（仅线上小镇）
========================

沿用28秒泡泡—白云时钟，不改泡泡轨迹、地标坐标、外墙四模式和自动轮播。

表演：微笑打量 → 鼓腮吹气 → 惊讶追云 → 单眼眨眼 → 挑眉偷笑 → 开心大笑 → 困倦哈欠 → 满足微笑。
嘴型由原先固定圆口改为曲线微笑、圆形吹气/惊讶、横向露齿笑、纵向哈欠；眼皮、视线、左右眉毛、脸颊同步过渡。

实现：sphereFacePerformance.js 纯函数按绝对时间取样；优先采用 bubbleExpression.timeMs，因此点击“吹泡泡”可同时重置表情和泡泡，避免两套时钟错位。
四个复用 Vector4 上传GPU，不增加网格、绘制调用、材质、贴图、定时器、网络请求或模型费用。
减少动态模式固定为睁眼微笑，不眨眼、不切换情绪。
使用现有画布与原有LED点阵/远距抗锯齿，眼球、地球、篮球模式不变。

测试：node --test tests/sphere-face-performance.test.js tests/sphere-landmark-render.test.js tests/sphere-bubbles.test.js
覆盖8段动作、嘴型差异、循环/任意跳转、无效时间、连续性、泡泡重置同步、减少动态、GPU资源复用。
