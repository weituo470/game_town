# 无人机编队第一视角

## 使用

进入「奇观 → 观看完整演出」，选择「编队第一视角」。本地直接入口为 `http://127.0.0.1:2571/?show=drones`。

- 可选右侧星盘、光环上缘、左侧星盘三个真实无人机机位。
- 镜头随该无人机自动起飞、变阵、归航和降落；这不是自由驾驶，也不是人物第一人称。
- 拖动场景或按方向键环视；展开「环视控制」可按住四向按钮；「回正镜头」恢复默认朝向。
- 「全景观演」随时切回导演镜头，不重置进度、暂停状态或速度。
- 暂停后可以环视与切换机位。「直达法相」跳至 1:16（手机端在「分幕与设置」中）；重播保留当前视角。
- 开启「减少动态」会退出机载视角，改用原有固定全景；关闭后不会自动切回移动镜头。
- 退出演出恢复进入前的地图视角，包括原有近身第三人称。鼠标锁定时先按 Esc 释放，再次按 Esc 退出。

## 实现边界

`DroneShow` 在帧优先级 -0.2 更新唯一的表演机群，`DroneCamera` 在 -0.1 读取同一个 `fleetRef`。机载镜头位置为所选无人机实际位置加 0.12 m 安装高度，不创建第二套机群或时钟，不修改无人机轨迹，不写入玩家位置或移动输入。

机位身份在 4096 和 2048 灯质量档之间保持一致：4042（右侧星盘）、2876（光环上缘）、1392（左侧星盘）。隐藏当前无人机自身的灯和尾迹，切回全景后恢复。高度读数来自无人机实际 world Y，不包含镜头安装偏移。

高光编队迁移期间，云台朝向按同一机群已有的演出进度在法相、光盘、巨翼朝向之间连续过渡，不改变镜头真实位置。全周期 20 ms 抽样及高光边界检查防止穿过旧中心点时突然转头。

沿用小镇的同一 Canvas、地形、建筑与夜景，没有增加独立场景或服务器协议。机载模式才绑定环视，切换/失焦/隐藏/卸载清理输入；观演时禁止场景点击误开 GPT 园区。

```powershell
node --test tests/drone-first-person.test.js tests/drone-fpv-integration.test.js tests/drone-show-clock.test.js tests/drone-camera.test.js
node --test --test-concurrency=1 tests/*.test.js

```

静态字号检查覆盖语义变量、局部覆盖、font 简写和媒体查询；仍需实际浏览器检查。验收使用 1440×900 桌面及 390×844 手机宽度，正常 16 px 根字号；新增控件至少 16 px/44 px，主要操作说明 18 px。

本次验收截图、测试日志和验收清单保存在 `qa-artifacts/drone-fpv-*`。仅验证本地预览，未部署公网。浏览器实测拖动、方向键及长按按钮；鼠标锁定生命周期另外由组件回归覆盖，不把自动化环境中的拖动回退误报为原生锁定成功。
