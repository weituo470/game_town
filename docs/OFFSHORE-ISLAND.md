# 远海浮动岛 · 南岸科考港

## 体验入口

- 小镇地图 → 远海浮动岛，或奇观 → 登船观景。
- 直接观景：`?landmark=offshore`（与小镇同一个 Canvas 和地图）。
- 码头在南岸，步桥接入现有道路；可步行或飞行前往。
- 登船 → 启航 → 离港 → 远海巡航 → 驻留 → 返航靠泊，完整航程约 150 秒。
- 提前返航沿原安全航线加速完成，最多 25 秒；不会瞬移穿越小镇。
- 导演全景、甲板看海、环绕船景可切换。关闭观景不会下船。
- 本版采用固定甲板观景站，不开放移动船上的自由行走、内舱或手动驾驶。
- 靠泊后才可上下船；船上禁止传送、跳跃、喷气和切换户外小游戏。

## 多人和时间

同房间共享一艘船和最多 8 个观景站，由服务器校验登船距离和航行指令。乘客、船体和镜头共用航行轨迹；昼夜预览和 180 秒小镇循环不会重置航程。短暂断线保留座位，重连可继续同行。真正离开房间后恢复单人港口状态。

协议版本为 8；旧版客户端应刷新后联机。任何船上游客都可以发起启航或提前返航，因此同行者需协商；这是科普演示，不是权限分级的船长系统。

## 视觉与标识边界

模型由 Three.js 程序化生成：双绿色浮筒、四白色立柱、开放月池、窗格舱楼、红白格构塔、黄色起重机、橙色救生艇和八角停机坪。新功能无付费生成请求，无新增外部素材下载或运行时依赖。

用户确认尚未取得校外使用官方组合标识的许可，因此船身与码头只使用系统普通字体书写“上海交通大学”，不使用、描摹或重新分发官方校徽/标准字标。界面明确标注“非官方科普模拟”，不暗示学校背书，不声称复现真实航行性能；尺寸、航线、进度均为游戏设计。

## 开发与回归

核心合同：`shared/offshore-island.js`。服务端权威：`server/TownRoom.js`。前端时钟与动作：`src/lib/useOffshoreCruise.js`。船体/码头生成器及 UI/镜头位于 `src/components/offshore/`。

```sh
npm test
npm run check:readability
npm run build -- --base=/game-town/
node scripts/check-loading-budget.mjs
```

专项测试覆盖路线连续性、返航、八席甲板变换、联机/重连/迟到访客、模型月池和净空、GPU 释放、控制交互、镜头包络及地图入口。静态字号检查不替代真实浏览器的桌面和约 390px 手机验收；绘制调用数不等于实际帧率。
