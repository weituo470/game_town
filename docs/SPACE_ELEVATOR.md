# 太空交通线 · 本机第二版

## 体验路线
1. 打开 http://127.0.0.1:4200/game-town/，点击“太空航线 · 高铁 / 电梯”。
2. “前往小镇高铁站”只使用原有游戏的命名目的地功能抵达**小镇车站**，不再跳到远海岛。
3. 列车停稳后从车门登乘。车外追随、车内视角可切换；WASD 在车厢局部地面行走。
4. 点击“关门发车”。先关门两秒，再沿约 600 米的真实管道线路跨海，约 28 秒抵达；不换网页、不换 Canvas。
5. 到站下车，步行约 25 米进运输厢。可用步行导航，它发送正常方向输入，不改变坐标；手动移动会取消引导。
6. 点击登梯，运输厢沿实体缆索升到近 100 km 的星环城，单程约 140 秒，含两端舱门停留。时间是游戏压缩，不是真实工程速度。
7. 星环城可行走、喷气，访问三座农业舱；回到实体停靠点可乘梯下降，再到高铁站登车返镇。

## 实现
- 仍为一个 R3F Canvas、一个 Scene。小镇不卸载，不使用 iframe、第二个渲染器、视频替代空间或到站页面跳转。
- 岛心 `(420,0,-380)`，距镇心约 566 m。小镇高铁站 `(36,0,57)`，远海站 `(405,0,-362)`。
- 城市中心 `(18000,100000,-27000)`，原星环内人物和建筑不缩放：内环半径150m、宽300m、环周约942m。
- 600 m 外护罩是真实几何，地面角直径约0.65°，像远方天体。接近时连续淡出，展现实体城市；细部远距离剔除只影响绘制，不切换世界。
- 重型运输厢、滑动舱门、夹持件、门架、钢索、海底基座、管道支架为原创程序建模。美术参考《流浪地球2》的重工业方向，不复制电影素材或声称1:1还原。
- 曲线路径和弧长表在 `shared/space-rail.js`。车厢局部坐标映射到移动列车；始发、到站和返程使用同一条曲线。
- 协议11：房间保存列车起程时刻与始发站；玩家保存 rail/ground/ascent/orbit/descent 和对应局部位置。客户端只发有序的意图，不接收客户端提交坐标或高度。
- 登车、离车只允许实体站点停稳时；空车呼叫只允许在另一站且无乘客。旧协议必须刷新。
- 太空电梯共享数学路径与端点映射。到站落地不再额外跳移4m。起终点有舱门停留，五次平滑加减速。
- 地球为程序化球体与大气外壳，是游戏视觉背景，不是地理数据或轨道力学仿真。

## 黑影修复
相机远裁面扩大后，SAO 的 scale/far、minResolution*far 和 blurCutoff*depthSpan 物理尺度必须保持不变。现在以原始420m镜头校准，并在异常/正常渲染后恢复参数；实时更新逆投影矩阵，HDR 遮蔽限制最大35%暗化，避免负色值形成黑/青色外轮廓。同时保留移动端及自适应质量的 AO 禁用策略，不再被逐帧逻辑重启。

## 验收与边界
- 本机浏览器完整登车、跨海、下车、步行登梯、100km到城与返程已验收。双 SDK 测试覆盖同步、移动、禁止途中离车、禁止快捷旅行绕过交通和请求重放。
- 整套测试、首屏加载预算和静态字号检查记录在上级 `space-transit-*.log`；浏览器证据在 `space-elevator-qa/transit-*`。
- 当前版本只更新本机，不部署公网、不推 GitHub、不修改原始星环分支或脏主工作区。
- 本机关闭所有收费AI/TTS/图像/角色生成与建筑师定时任务。
- 初版没有缆索弹性、轨道力学或货舱碰撞仿真。电梯乘坐段锁定乘客位置；环城农场资源仍是本机存档，不是共享经济。
- 列车为房间共享实体；电梯沿用个人航程状态。多人同乘同一升降批次、轨道站复杂调度尚非本次范围。
- 城市车辆驾驶、原分支全部控制台、星球级海岸精确地形未纳入。

## 运行
在本目录运行：
```powershell
npm run build -- --base=/game-town/
node scripts/check-loading-budget.mjs
npm run check:readability
node --test --test-concurrency=4 tests/*.test.js
```
在上级 `qa/deploy` 运行 `node space-elevator-preview.mjs`。仅监听127.0.0.1，进程收据见 `space-elevator-preview-service.json`。
# 2026-10-23：远海自动航线

- 电梯岛中心移至 `(1100, 0, -1040)`，离小镇约 1.5 公里；远海站按岛坐标生成，避免视觉轨道与服务端登乘区域不一致。
- 单程列车运行 48 秒，发车关门缓冲 2 秒，两端各停站 18 秒。无乘客时同样自动往返，联机由服务端调度，离线使用同一确定性规则。
- `railEpoch < 0` 表示在其绝对值时间前开门等待；正数表示实际发车时间。`advanceRailSchedule` 可跨越后台挂起时间恢复正确车次，不重置轨道位置。
- 操作：右下角“太空航线” → “前往小镇高铁站” → 停站登乘 → 远海站下车 → “步行登舱 · 抵达后升空”。引导只发送普通方向输入，WASD 可取消，不向服务端传送坐标。
- 电梯默认舱内乘坐视角，途中可切到舱外追踪；140 秒连续升空后抵达可步行的真实星环城，仍是同一 Canvas / Scene。
- 协议升级至 12，旧客户端需刷新，以免使用旧岛坐标。
