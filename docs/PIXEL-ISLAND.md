# 方块原野 · 像素岛

这是《游戏小镇》中的原创体素沙盒首版，借鉴挖掘、采集、合成与自由建造的通用玩法。**不是完整的《我的世界》，也没有复制其源代码、纹理、音乐、商标或专有素材。**

## 入口与模式

- 在小镇首页点击「方块原野 · 像素岛」，或从小镇导览进入。
- 深链接：在当前应用地址后使用 `?landmark=pixel-island`。应用部署在子路径时保留该子路径，例如 `/game-town/?landmark=pixel-island`。
- **采集建造**：挖掘资源，获得库存，按配方合成建筑材料；放置会消耗对应库存。
- **自由创造**：快捷栏材料无限供应，可以切换飞行，以便在空中搭建。

像素岛沿用小镇的同一个 Three.js / React Three Fiber Canvas，不另开网页，也不创建第二个渲染器。它位于世界坐标 `(120, 210)` 附近，占地约 96 × 96 米。原始地形包含海滩、草地、树林、矿洞和北部雪峰；世界网格为 `64 × 40 × 64`，一格边长 1.5 米。

| 操作 | PC 键鼠 | 触屏 |

| 移动 | WASD / 方向键 | 方向按钮 |

| 选材 | 1–9 / 鼠标滚轮 / 点击快捷栏 | 点击快捷栏；横向滚动可查看全部九格 |
| 背包与合成 | E / 顶部按钮 | 「背包 / 合成」 |

方块操作最远距离为 8 米。基岩不能破坏，不允许把方块放入自己的身体范围。离开页面焦点、隐藏标签页、打开面板或退出像素岛时应停止持续移动与挖掘。

## 本机存档，不是多人共享建造

**当前为单人沙盒。修改、库存和进度只属于当前浏览器，不会上传到服务器，也不会同步给房间中的其他玩家。**

- 使用 `localStorage`，键名为 `game-town.pixel-island.v1`。
- 方块变更会触发延迟自动保存；存档面板也提供「立即保存」。
- 支持导出 JSON 世界备份，以及导入本游戏认可的有效备份。
- 导入成功会替换本机世界；应先导出旧世界备份。
- 「重建原始岛屿」需要再次确认，会清除当前本机方块改动和库存，不影响小镇其他玩法。
- 清理浏览器数据、更换设备、切换浏览器或更换网站源地址后，不能假定旧存档仍然存在。先导出再迁移。
- 浏览器不允许存储或空间不足时，仍可游玩，但应按界面提示导出 JSON；不能把错误提示当作保存成功。
- 无法读取的旧存档不会被静默覆盖；可以导出当前临时作品，或者明确选择重置。
- 存档有格式、坐标、方块 ID、数量与体积校验；最大方块差异数 12,000，文件最多 10 MB。这是数据保护边界，不是 AI 生成额度。

在普通小镇视角，岛屿使用确定性的原始支撑地形。进入单人沙盒后，由体素控制器处理可编辑方块的碰撞。联网人物留在服务器认可的入口/原位置，不向服务器提交沙盒中的私有编辑坐标。其他访客看到的并非你的本机建筑，这一点不应在演示中误称为「联机建造」。

## 代码分层

| 模块 | 职责 |
| --- | --- |
| `shared/pixel-island.js` | 原始地形、世界坐标、海岸支撑与命名入口；纯函数，不读取用户存档 |
| `shared/pixel-world.js` | 体素数组、采集、放置、合成、射线、玩家碰撞及存档校验 |
| `src/components/pixel/PixelGate.jsx` | 延迟挂载；显式进入或靠近岛屿后再加载重型模块 |
| `src/components/pixel/PixelIsland.jsx` | 分块网格、场景内输入、第一人称镜头和粒子效果；沿用原有 Canvas |
| `src/components/pixel/pixelRuntime.js` | 本机运行状态、输入、进度、自动存档与 UI 订阅 |
| `src/components/pixel/pixelVisual.js` | 原创像素材质、可见面几何及方块粒子 |
| `src/components/pixel/PixelControls.jsx` / `pixel.css` | 快捷栏、触屏操作、暂停、合成、帮助与存档面板 |

基础小镇、自然岛、都市岛和既有节目不依赖体素生成器。像素岛使用懒加载，16 个横向区块只生成外露面；修改后更新受影响区块。像素渲染配置关闭屏幕空间 AO，避免挖掘和第一人称移动时支付额外的大面积后处理成本。首次进入的实际加载时间和帧率仍需通过浏览器测量，静态预算不能替代实机证据。

## 首版明确不包含

- 怪物、动物 AI、战斗、生存饥饿/生命系统。
- 红石、电路、复杂自动化、液体传播。
- 多人共享建造、跨设备云存档、反作弊与服务器编辑权限。
- 无限世界、无限高度、正版 Minecraft 的完整配方及兼容存档。
- 收费模型调用；本模块不需要 LLM、外部素材服务或 API 密钥。

## 回归与人工验收

在项目根目录运行：

```powershell
node --test tests/pixel-island-world.test.js tests/pixel-integration.test.js
npm run check:readability
npm run build
node scripts/check-loading-budget.mjs
```

同时运行体素引擎和运行时对应测试（若新增），并执行既有小镇、自然岛、都市岛、天空、节目和联机回归测试。测试需要本机回环网络时，沙盒网络权限错误不应误判成玩法错误。

真实浏览器验收至少覆盖：

1. 桌面正常 100% 缩放，以及约 390px 手机宽度；检查正文至少 18px、按钮至少 16px、次要元信息至少 14px，不靠整体缩放压小界面。
2. 入口、全景、采集/自由创造切换、长按挖掘、放置、快捷栏、合成和第一人称碰撞。
3. 键鼠与触屏后退/上升、Esc、失焦、面板开关、返回小镇时无粘键和鼠标锁泄漏。
4. 保存、刷新恢复、导出/导入、损坏存档保护、重建二次确认。
5. 非像素玩法的 E/F 快捷键、节目镜头、天光阴影和房间联机未被沙盒抢占。
6. 检查长文字换行、面板滚动、快捷栏横向滚动、遮挡和页面横向溢出。静态 CSS 检查通过不等于实屏验收完成。
