# 足迹 · 向光而行：水平空心脚印修订

104秒虚拟烟花秀。按用户反馈，先模仿2008北京奥运《历史的足迹》的关键视觉，而不是另造竖直实心脚掌。

## 参考及边界
- 已查看蔡国强官网的现场照片：https://caiguoqiang.com/projects/projects-2008/beijing-olympics/
- 对照照片：横卧在天空中的空心外轮廓、跟随路线的透视纵深、由向上运动的焰火显出轮廓。照片与奥运原音轨均未放进项目。
- 不使用奥运标志，不称为官方演出。保留原有其它节目。

## 同一批粒子的完整过程
1. 29步，左右交替，2.1秒一步。每步轮廓平铺在世界XZ平面，所有轮廓顶点高度相同；不再将局部脚掌直接立在XY平面。
2. 闭合曲线保留脚跟、内侧足弓和五趾起伏。沿弧长均匀布置64个发射位置（低画质36个），不向内部填点。
3. 每处发射位置中的同一批粒子经历1.85秒升空，抛物/正弦减速到顶点。四个分支在爆开前重合成一束，顶点时做局部扩散，六个延迟样点构成离散彗尾。
4. 上升函数与爆后函数在顶点位置完全相等。爆开亮度以100毫秒平滑提升，不用在爆炸时启用一张新脚印点阵。
5. 爆后火星持续受阻力、重力影响，拖尾下落；最后0.8秒平滑衰减到零。保留可见灯点间距，不使用线条、灯管或突然替换模型。
6. 绝对时间驱动；暂停、任意跳转、减少动态、退出销毁都复用原来的控制器。仅两次Points绘制，粒子缓冲只创建一次。

## 真实爆炸音效
使用作者Rudmer_Rotteveel的CC0素材“Whistle and Explosion Single_Firework”：
https://freesound.org/people/Rudmer_Rotteveel/sounds/336008/

许可与来源：public/licenses/footprint-fireworks-audio.txt；公开预览原文件保留在public/audio/sources/firework-336008-cc0.mp3。

脚本测量5ms RMS最响窗口，将原录音爆响峰值（1.1775秒）对齐每次视觉爆开后65ms，再混入原创低频、回声和余烬噼啪。不是把一段音频独立循环。104秒音轨只在选中节目后载入；播放、暂停、跳转继续跟随节目时钟。

重新生成：python scripts/create-footprint-soundscape.py（numpy、ffmpeg）。
