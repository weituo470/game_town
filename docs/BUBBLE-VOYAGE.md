# 球幕泡泡与一键出海

## 游玩
- 南岸码头附近按 E，或点击触屏“登船并出海”，一键登船并自动离港。
- 小镇地图“登船并出海”进入同一流程；观景面板仍提供“仅登船”。
- 航程约 150 秒，显示距港距离和预计靠港时间；海上可提前返航，靠港后下船。
- 球幕黄色小人自动鼓腮吹泡泡。泡泡从嘴部脱离，升空后化成白云，再缓缓漂散。
- 点击“吹泡泡”切回黄色表情并从头播放；自动轮播先完整播放表情故事再换片。

## 实现边界
- 同一张地图、同一个 Canvas。泡泡不阻挡人物，不产生碰撞，不使用付费服务。
- 气泡与云为程序化几何和着色器，两个实例批次，8 个生命周期槽，28 秒循环。
- 减少动态模式使用固定气泡与云，不循环漂移。昼夜预览不改变多人航程。
- 联机一键操作先等待服务器登船确认，再等待 350ms 冷却，才发送一次启航指令。
- 断线、换房、拒绝、超时会取消未完成自动操作，不悄悄重试或再次启航。
- 原航线、协议、座位、150 秒时长和服务端判定均不变。距港为游戏坐标示意，不是现实导航。
- 上海交通大学校名仍为普通字体；未使用官方校徽、字标或背书。
