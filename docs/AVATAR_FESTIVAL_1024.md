# 法天象地 · moonstone × 1024

本次为现有 150 秒演出加入两个实际三维无人机点阵，非屏幕字幕。

- 00:24–00:29：机群从星河渐变为文字；00:29–00:36 稳定展示 `moonstone` / `黑客松`；00:36–00:44 连贯幻化为翼龙。
- 00:44–01:48：保留蓝焰翼龙、幼年悟空、四阶失重及复燃。
- 01:48–01:55：同一机群变为 `1024` / `程序员节快乐`；保留 UFO 捣乱和球幕激光高潮。02:09–02:14 镜头从球幕平滑回到祝福灯阵。
- 02:14–02:20：祝福定格；02:20–02:30 同一批飞机从文字位置平滑回到各自真实起降位，熄灯收束。
- 两个独立文字快捷入口位于“分幕与设置”。既有右键拖动、滚轮和方向按钮仍可使用；方向按钮收纳进“调整观演视角”，避免遮挡演出。

## 实现与复现

`src/components/drone/avatarFestival.js` 对既有飞机缓冲区按确定性节目时间采样，保持 4096 / 2048 个永久身份；不创建另一批无人机，也不使用线段或灯管连接字形。原有自由落体区间完全不变。中文字形坐标由 `scripts/build-avatar-festival-glyphs.py` 在 Windows 使用本机雅黑生成，发布的是四句固定文字的离散坐标，不分发字体文件。灯点间隔与渲染尺寸经过桌面/390px 手机实屏验收。

DroneShow 和 DroneCamera 在独立 Suspense 中按需加载，字体与观演几何不阻塞可游玩小镇。未提高 1.9 MB 首屏 JavaScript 上限。

## MP4

法天象地观演页的“导出 MP4”→“从头录制 MP4”会以 1× 从头播放并在本机采集 1280×720 画布。目标 30 fps，实际依设备性能；请保持前台。不会采集 HTML 面板、桌面或麦克风，也不会上传视频。此节目当前导出**无声音轨**，界面明确标注。已有带配乐 AI 样板的音轨封装不受影响。

使用现有原生 MP4 / WebCodecs H.264 编码器与真实 MP4 封装；不将 WebM 改扩展名伪装为 MP4。无可用编码器时明确提示，允许手动选择 WebM。全片完成后显示预览和下载按钮，可保留片段、取消或重录；录制期间锁定跳转、倍速与节目切换。
