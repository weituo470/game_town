# 两分钟内的导演短秀与 MP4 导出

## 本轮替换

上一轮三套长篇图案轮播样板已从菜单移除。现在的固定样板由本次会话直接编排，不调用线上模型；公共 AI 即兴/命题生成 API、模型配置、配额与密码规则不变。

入口：演出节目单 → AI 即兴 / 命题演出 → 短篇试映。

| 节目 | 总时长 | 主体与高光 |
| --- | --- | --- |
| 焰羽·重生 | 1:48 | 立体凤凰的喙、躯干、羽翼和长尾；折翼俯冲、低空停顿、复燃反升、金柳礼花 |
| 鲸落·潮生 | 1:58 | 母鲸呼唤、幼鲸回应、五鲸团聚、共同跃空、护幼归航；原创器乐配乐 |
| 天门·逆重力 | 1:40 | 立体星门、悬浮核心；收束、机群失重、临海制动、逆重力反升、四方烟花 |

每场包含一次完整起飞、归航和熄灯。表演是虚拟视觉编舞，不是实体飞行指令或真实焰火操作指导。所有无人机沿用固定 4096/2048 身份，保持可辨认的独立灯点，不以发光管线替代机群。烟花是独立的粒子特效，包含升空、开花、重力落瀑和自然熄灭。

## 导演与性能

新样板不再套用公共 AI 图案编译器，而是本地固定、纯绝对时间的立体动作脚本；网络输入不能载入或改写这些脚本。镜头从小镇起飞建立空间关系，随后靠近主体；失重段保持镜位稳定，让观众看清高度变化。高潮时适当拉远，留下烟花的边缘空间。

暂停、拖动时间线、跳幕、重播与导出使用同一时间轴。减少动态时关闭烟花和俯冲，保持固定全景。手机竖屏增大取景距离，不缩小正文或横向裁切主要形体。

烟花使用固定 GPU 粒子池与绝对时间 shader，复用已有 Three/WebGL/后期，不增加动态光源、第二渲染器或远端素材。样板内容和烟花仍在懒加载路径，不能进入首屏依赖树。旧法天象地、水滴与空天母舰演示保持原样。

## MP4

观演中选择「导出 MP4 → 从头录制 MP4」，实时录下当前演出的画布与运镜。目标 1280×720、30fps；实际帧率取决于设备与浏览器前台渲染，并非承诺固定 30fps。短秀录制约需对应片长，请将窗口置于前台；低帧率时会提示。鲸群故事包含原创配乐，其余两秀仍为无声画面，所有节目均无旁白。

只采集小镇 WebGL 画布，不采集 HTML 操作面板、桌面、麦克风或系统音频，不上传文件。优先原生 H.264 MP4，备用路径懒加载 Mediabunny/WebCodecs H.264；不支持时明确提示真实 WebM 备选，绝不改后缀冒充 MP4。录制时锁定跳转和倍速，可以停止保留片段或取消。

鲸群故事录制结束后，浏览器将原创配乐按实际视频时长裁剪，封装为 MP4 的 AAC 音轨或 WebM 的 Opus 音轨；保留原视频编码，不重复压制画面。手动停止的片段加入短淡出。观演静音只影响扬声器，不移除导出影片的配乐；若浏览器不能编码音频，界面明确注明无声视频与失败原因，不伪装成功。

## 鲸群归航配乐

118 秒原创器乐与演出共用绝对时间轴，支持暂停、进度跳转、两倍速、后台暂停和退出停止。点击观看后尝试播放；浏览器阻止自动播放时显示「开启配乐」。母鲸的低音呼唤由幼鲸的高音钟琴回应，84 秒共同跃空进入合奏高潮，100 秒开始收束，118 秒自然结束。

音频位于 `public/audio/whale-homecoming.mp3`，来源与校验值在同目录 JSON；生成器为 `scripts/render-whale-score.py`（Python 3、numpy、FFmpeg）。旋律、合成乐器与渲染音频均为本项目原创，沿用 MIT 条款，没有外部歌曲、采样或付费模型调用。配乐与封装模块懒加载，不阻塞小镇首屏。

Mediabunny 1.61.6 的 MPL-2.0 与来源声明保留在 `public/licenses/`；本轮不更换依赖。项目自有新增代码沿用 MIT。

## 验收

```sh
npm test
npm run check:readability
npm run build
node scripts/check-loading-budget.mjs
```

还需实际浏览器查看三秀的成形、高光、低空动作、烟花和归航；桌面与 390px 下核验字号/布局。静态测试只证明约束，不代表美术质量。导出须检查真实 MP4 容器、时间戳、可解码性和非黑画面；鲸群影片还要确认音轨实际存在、音视频时长一致。测试环境节流不能被宣称为 30fps 达标。
