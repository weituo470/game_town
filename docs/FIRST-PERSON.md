# 近身第三人称漫游

项目：游戏小镇。目录：`<project-root>`。

这是一种在现有小镇里探索的相机模式，不是新增射击小游戏。2026-10-18 按最新需求，将原第一视角替换为主角后上方的近身第三人称：人物可见，支持跳跃和全区域喷气背包。内部 `viewMode` 字符串仍保留 `first-person`，仅为兼容已有相机切换、输入与样式接口，不代表当前仍是眼睛视角。

## 镜头构图与避障

- 桌面镜头距离主角胸口焦点 **4.4 米**、垂直视野 **58°**；不是原来的远距离“跟随人物”模式。
- 竖屏画布宽高比小于 0.75 时，镜头调整为 **5.2 米 / 62°**，让人物全身与触屏控件有更多空间。桌面参数不变。
- 主角默认模型与已选生成模型均保持可见。相机以人物高度加 1.15 米为焦点，环视绕人物进行，初次进入从主角背后观察。
- 镜头沿整个后退路径每约 16 厘米检查小镇碰撞和障碍高度，并留出镜头半径；遇到建筑、喷泉等会缩短距离。极窄角落采用近头顶退让，不将镜头埋入角色头部。
- 高空飞行超过障碍物高度时可恢复正常镜头距离；避障只改变相机，不改变人物位置、飞行高度或服务端状态。靠近出生点喷泉时，5.2 米竖屏镜头也可能因避障而缩短。

## 桌面操作

1. 打开 [本机小镇](http://127.0.0.1:2571/)，在相机工具条选择 **近身视角**（近身第三人称）。原来的 **全镇鸟瞰**、**跟随人物** 仍可随时切换。
2. 点击场景开始鼠标环视。只有这次明确点击会申请鼠标锁定；选择模式、打开页面或恢复窗口焦点不会自动锁鼠。
3. 使用 **WASD / 方向键** 移动。前后左右以当前视线的水平朝向为准；抬头或低头不会改变行走速度。轻按 **空格** 跳跃，长按超过约 0.22 秒使用喷气背包上升，松开下降，空中可以再次点火；焦点位于按钮、链接或输入框时保留控件本身的键盘操作。
4. 靠近店门后按 **E**，或点击“进入体验”。小游戏、玩家护照与街区导览沿用原有流程。
5. 按 **Esc** 释放鼠标，再点击地图、菜单或其他视角按钮。Esc 不会强制退出近身第三人称；重新点击场景才会再次申请锁鼠。解锁会清除持续输入并停止喷气推力，空中人物自然下降，不瞬移到地面。

浏览器不支持、拒绝或限制鼠标锁定时，提示会切换为“拖动画面环视”。按住鼠标左键拖动即可调整视线，WASD 仍可移动；不需要修改浏览器安全设置。拖动结束不会顺带申请锁鼠。

## 触屏操作

- 在场景内拖动调整视线，使用左下方向按钮移动。
- 可以先按住方向按钮，再用另一根手指拖动场景；环视只跟踪开始这次拖动的那根手指。
- 轻点“跳跃 / 喷气”按钮跳跃，长按喷气、松开下降。可以同时按方向按钮并用另一根手指拖动场景环视；结束环视不会释放另一根手指持有的喷气输入。
- 近身第三人称下，方向按钮、地图导航和喷气背包入口不会把模式切回远距离跟随；相机工具条可主动切回。
- 窄屏工具条重排，不通过缩小文字维持一行。环视提示不拦截场景的触摸事件。

## 与现有小镇的关系

- 相机在人物后上方；当前玩家、其他联机玩家均正常显示。人物位置不因切换相机而改变，空中切入近身视角保持原飞行朝向。
- 近身第三人称和其他视角共用移动、建筑/喷泉碰撞、地图边界、全区域喷气背包和服务端输入校验，没有独立的“穿墙路线”。
- 联机仍发送世界方向输入，沿用服务端权威位置与客户端预测校正；相机是本地显示选择，不要求其他玩家使用相同视角。
- 打开弹窗、窗口失焦或页面隐藏会清理移动和喷气输入，并释放本场景持有的鼠标锁定；飞行中的停推力不会重置高度。联机其他玩家不受影响。
- 店铺入口提示保持可见。大型介绍、旅程卡片等非必要信息在近身模式收起，为角色和街景留出空间。钓鱼、跳一跳仍沿用各自原有的户外挑战镜头，不将它们改成喷气背包。
