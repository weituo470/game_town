# 球幕守卫 · 法天象地联演

球幕不再独自轮播：法天象地的同一条演出时钟驱动外墙朝向、颜色、眼神、眉毛与嘴型，并在无人机归航时演一段 UFO 捣乱喜剧。自动夜场和手动观演都生效；其它节目不触发，结束后恢复原外墙和泡泡。

## 节拍（沿用原 2 分 30 秒节目，不延长夜场）

- 0:00—0:36：期待机群起飞，抬眼追望星河。
- 0:36—1:08：冰蓝色惊讶看龙，再迎接少年成相。
- 1:27—1:35：失重时担心，复燃后放松欢呼。
- 1:50：原创碟形 UFO 从远海飞入，薄盘装甲、绿色玻璃穹顶、环形信标、卡通驾驶员。
- 1:54：UFO 摇摆挑衅、投下一段不触地的紫色探照光。
- 1:56—1:58.5：小人转向锁定，眉毛压低，脸色由金黄转为警戒橙，双瞳青白蓄能。
- 1:58.5—1:59.8：两道眼神激光连续命中飞碟；命中闪光是局部效果，不做全屏闪白。
- 1:59.8—2:07.8：飞碟失控翻滚，带少量批处理碎片落向无地表的远海。
- 2:07.8—2:11.5：水花与涟漪扩散；不伤害玩家，也不修改地形／建筑／碰撞。
- 2:10—2:20：小人得意眨眼、微笑谢幕，镜头平滑回到无人机归航。

## 模块与边界

- `shared/sphereUfoShow.js`：纯函数绝对时间编舞、姿态、色彩、眼部炮口世界坐标和坠海轨迹。支持任意跳转、暂停和晚加入，不用计时器累积位移。
- `createSphereUfo.js`：原创建模，至多 23 个绘制对象、96 个水花点、18 个实例碎片；无新纹理、下载、灯光、相机、渲染器或模型服务。第一次联演才分配，离开隐藏，卸载幂等释放资源。
- `SphereLandmark.jsx`：仅法天象地收到节目私有时钟，普通外墙继续使用自身单调时钟。联演时暂收泡泡，退出恢复。
- `createSphereLandmark.js` / `sphereWallShaders.js`：原有 LED 外墙增加两项复用 uniform，保留眼眉嘴表情向量；整栋建筑不旋转，只改变画面朝向。
- `sphereUfoCamera.js`：观演镜头根据球幕与 UFO 两个主体计算合适视距，适配桌面和竖屏，镜头转入／转出连续；自由探索和编队第一视角不应用该镜头。
- 节目“分幕与设置”中增加“球幕反击 · UFO 彩蛋”（1:50）和“眼神激光 · 高光”（1:59.3）。已有暂停功能可用于逐帧观赏。
- 减少动态：不发射快速激光、不爆闪、不翻滚坠落，保留静态角色反应。音频仍遵循原节目显式开启规则；没有新的收费调用。
