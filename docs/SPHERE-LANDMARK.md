# 球幕剧场：同地图 LED 外墙地标

## 使用

- 小镇顶部「奇观」或「小镇地图」打开球幕剧场观景。
- 也可访问 `?landmark=sphere` 直接观景；「走到广场」回到人物探索。
- 外墙可选择黄色表情、巨型眼球、蓝色星球、篮球，或自动轮播。
- 「环绕观看」提供缓慢侧向运镜；减弱动态模式冻结自动动画，保留手动换片。
- 白天/夜晚预览仅作用于当前访客，不同步其他房间玩家。

## 世界与碰撞

球体位于西侧虎鲸湾外缘，中心 `(-108, 10)`，半径 18；使用暖石基座、玻璃裙楼、环形步道与连接桥。不是独立 iframe 或第二个 WebGL 场景。

共享合同 `shared/sphere-landmark.js` 同时定义模型尺寸、岛屿可走范围、实体碰撞、桥与到达点。球面高度用于飞行避障和降落，禁止从地面直接穿入建筑。玩家仍能喷气飞行与悬停；本轮没有室内空间。

## 渲染与性能

- 单 Shader 程序化外墙，无视频下载、图片贴图或新的模型服务调用。
- 黄脸眨眼、视线与嘴型；眼球虹膜；旋转蓝色星球及云层；篮球纹理。
- LED 网格使用导数抗锯齿，近处可辨灯点，远处保留整体画面。
- 自动轮播 72 秒，每片 18 秒，交接渐变；后台隐藏时暂停更新。
- 模块懒加载；预算约 11 draw calls、18,256 三角面。复用现有 Three.js，不新增依赖。
- 观景运镜使用单调渲染时钟，避免小镇昼夜/NPC 周期回绕造成相机跳跃。

## 可重复验证

```sh
npm test
npm run check:readability
npm run build -- --base=/game-town/
node scripts/check-loading-budget.mjs
```

专项测试：`tests/sphere-landmark.test.js`、`tests/sphere-landmark-render.test.js`、`tests/sphere-viewer.test.js`。字体回归沿用项目全量 CSS 扫描；正文至少 18px，控件至少 16px、44px 高，辅助署名 14px。

实屏验收需覆盖桌面、390px 手机、四种外墙、昼夜、环绕、退出/重进、地图入口、人物到达与喷气悬停。静态测试和构建不代替浏览器验收。

## 素材与边界

这是参考球形 LED 建筑概念的原创程序化致敬，不是官方 Sphere 项目，也不包含 Sphere 官方商标、影片、地图纹理或外墙原始素材。蓝色星球使用程序化轮廓，不作为精确地理图。已有其他场景和素材许可证不因本模块改变。
