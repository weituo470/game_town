# AI 立体舞台编舞 V2

## 用户可见变化

新生成的命题与即兴节目采用同一套 V2 编舞能力，不再将整场节目简化成单一二维图形轮播。每次模型输出 2–4 个持续角色及 4–6 幕故事，控制演员组合、动作、大小、构图、镜头及少量高潮烟花。演员库包括鲸、凤凰、游龙、灯笼、莲花、蝴蝶、立体城市、星球、星门、彗星和光树。

角色几何与运动来自有界的本地引擎，模型负责组合和叙事，而不是播放固定的精选节目。主题不在演员库中时，模型以相近的视觉意象表达，不宣称可以生成任意三维模型。

完整节目包含 12 秒起飞、最多 92 秒正文、12 秒归航和 2 秒熄灯，最长 118 秒。烟花与编舞共用绝对时钟，可暂停、拖动进度、变速及使用原有录制导出。新生成节目暂不自动生成配乐；既有精选节目的配乐保持不变。

## 安全与质量

- 只接受有界 JSON 数据，不执行模型代码、着色器、URL 或远程资产。
- 角色、动作、镜头和特效均使用严格白名单；坐标、点数分配与安全高度由引擎决定。
- 要求构图、镜头、动作变化与多演员互动，并保留跨幕主角连续性。结构性质量不足时明确拦截，不偷偷替换为固定样板。
- 每次生成仍只调用一次提供方；失败或取消不自动再次收费调用。
- 沿用现有生成次数配置，不增加密码或新的每日次数上限。
- 继续使用单个 4096 / 2048 点机群；独立粒子、无连线、无灯管式光晕。烟花复用 8000 火花点 / 512 升空点 / 两个绘制调用的上限。
- 保存的 V1 线描节目仍以原运行时回放，不清空本机节目库。重新生成才使用新版能力。
- 手工精选鲸群、凤凰、星门及其它小镇演出不替换、不改写。

## 回归入口

`npm test` 包含协议白名单、安全边界、故事质量、V1 兼容、确定性运动与有界烟花测试。`npm run check:readability` 是静态字号门禁，不能替代桌面和 390px 浏览器实屏检查。

上线还必须检查真实主题与即兴模型结果，并在浏览器查看核心幕、烟花、完整归航、移动端取景和控制界面；测试通过不自动等于艺术效果合格。
